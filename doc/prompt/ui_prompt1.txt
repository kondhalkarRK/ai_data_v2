The Proactive Engine automatically surfaces insights 
the user has NOT asked for — based on the loaded dataset.

Implement class ProactiveEngine:

METHOD 1: generate_proactive_insights(
    df: pd.DataFrame,
    context: dict | None = None
  ) → list[dict]

  Runs automatically when data is loaded.
  Returns list of insight cards, each:
  {
    "type": "trend" | "outlier" | 
            "top_performer" | "drop" | 
            "growth" | "concentration",
    "title": str,
    "summary": str,
    "metric": str,
    "value": float | str,
    "change": float | None,
    "direction": "up" | "down" | "neutral",
    "confidence": "high" | "medium" | "low",
    "chart_hint": "bar" | "line" | "pie",
    "suggested_question": str,
    "priority": int (1=highest)
  }

  Detection logic — run ALL of these:

  A) TOP PERFORMER DETECTION:
     For each numeric column:
     - Find top value and who holds it
     - Find bottom value
     - Calculate gap between top and bottom
     - If gap > 2x average: high confidence insight
     - Insight: "X leads [metric] at Y, 
                 which is Z% above average"

  B) TREND DETECTION:
     If date column exists:
     - Group by month/period
     - Calculate period-over-period change
     - If last period change > +10%: 
       "upward trend" insight
     - If last period change < -10%: 
       "downward trend" insight

  C) CONCENTRATION DETECTION:
     For each categorical column:
     - Calculate % of total held by top value
     - If top value > 40% of total:
       "concentration risk" insight
       "X category holds Y% of all revenue"

  D) GROWTH OPPORTUNITY:
     - Find dimensions where metric is 
       below average AND has positive trend
     - Flag as "growth opportunity"

  E) SUDDEN DROP:
     If most recent period < prior period by >15%:
     Flag as urgent priority-1 insight

  Limit to top 5 insights by priority.
  Cache result in st.session_state["proactive_insights"]
  Only regenerate if df changes (use df hash)

METHOD 2: format_insight_card(insight: dict) → str
  Returns HTML string for rendering insight card

METHOD 3: get_suggested_questions(
    df: pd.DataFrame,
    limit: int = 5
  ) → list[str]
  
  Returns smart suggested questions based on:
  - Available columns in df
  - Detected metrics from metric_registry
  - Prior proactive insights found
  - Examples:
    "Which [category_col] has highest revenue?"
    "Show revenue trend by month"
    "Top 10 [dimension] by [metric]"

The What-If Engine answers forward-looking scenario 
questions on CSV data using statistical simulation.

Implement class WhatIfEngine:

METHOD 1: detect_whatif_query(question: str) → bool
  Returns True if question contains:
  - "what if"
  - "if X changes by Y%"  
  - "suppose"
  - "assume"
  - "simulate"
  - "scenario"
  - "if we increase/decrease"
  - "what would happen"
  - "what happens when"
  - "project" / "forecast"
  - Numeric % change pattern

METHOD 2: parse_scenario(question: str) → dict
  Extracts scenario parameters:
  {
    "metric": str | None,
    "dimension": str | None,
    "change_type": "increase" | "decrease" | 
                   "set_to" | "multiply",
    "change_value": float | None,
    "change_unit": "percent" | "absolute",
    "filter": dict | None,
    "time_horizon": str | None
  }
  
  Examples:
  "what if revenue increases by 20%"
  → metric=revenue, change_type=increase,
    change_value=20, change_unit=percent

  "what if we had sold 500 more units"
  → metric=units_sold, change_type=increase,
    change_value=500, change_unit=absolute

  "what if Ford sales drop by 15%"
  → metric=revenue, dimension=make,
    filter={make: Ford}, change_type=decrease,
    change_value=15, change_unit=percent

METHOD 3: run_scenario(
    df: pd.DataFrame,
    scenario: dict
  ) → dict

  Applies scenario to DataFrame and returns:
  {
    "baseline": {
      "value": float,
      "label": str,
      "breakdown": pd.DataFrame
    },
    "scenario": {
      "value": float, 
      "label": str,
      "breakdown": pd.DataFrame
    },
    "delta": {
      "absolute": float,
      "percent": float,
      "direction": "up" | "down"
    },
    "narrative": str,
    "chart_data": pd.DataFrame,
    "assumptions": list[str]
  }
  
  Implementation:
  1. Calculate baseline from actual df
  2. Apply change to a df copy:
     - percent change: multiply column values
     - absolute change: add to column values
     - dimension filter: apply only to subset
  3. Calculate scenario result
  4. Build delta comparison
  5. Generate narrative:
     "If revenue increased by 20%, total 
      revenue would rise from £1.2M to £1.44M,
      an increase of £240K (+20%)"
  6. Build side-by-side chart data

METHOD 4: generate_whatif_narrative(
    scenario_result: dict
  ) → str
  
  Returns rich narrative string:
  - Baseline context sentence
  - Scenario change sentence  
  - Impact sentence
  - Key assumption list
  - Confidence statement
  Format suitable for chat narration display

The Smart Anomaly Engine detects statistical 
anomalies in the loaded dataset automatically.

Implement class AnomalyEngine:

METHOD 1: detect_anomalies(
    df: pd.DataFrame,
    sensitivity: str = "medium"
  ) → list[dict]
  
  sensitivity: "low" | "medium" | "high"
  low    = 3 std deviations
  medium = 2 std deviations  
  high   = 1.5 std deviations

  For each numeric column:
  A) Z-SCORE ANOMALIES:
     - Calculate mean and std
     - Flag values beyond sensitivity threshold
     - Return top 5 most extreme anomalies
  
  B) IQR ANOMALIES:
     - Calculate Q1, Q3, IQR
     - Flag values < Q1-(1.5*IQR) 
       or > Q3+(1.5*IQR)
     - Useful for skewed distributions
  
  C) TEMPORAL ANOMALIES (if date column):
     - Group by time period
     - Detect periods where value 
       deviates > threshold from rolling mean
     - "Sales in March were 43% below 
        the 3-month rolling average"
  
  D) CATEGORICAL ANOMALIES:
     - For grouped data: find categories
       where metric deviates from group mean
     - "Ford SUV revenue is 2.8x higher 
        than average SUV revenue"

  Each anomaly dict:
  {
    "type": "outlier" | "temporal" | 
            "categorical" | "pattern",
    "column": str,
    "dimension": str | None,
    "value": float,
    "expected": float,
    "deviation": float,
    "deviation_pct": float,
    "direction": "high" | "low",
    "severity": "critical" | "warning" | "info",
    "description": str,
    "suggested_question": str,
    "row_reference": dict | None
  }

METHOD 2: summarise_anomalies(
    anomalies: list[dict]
  ) → str
  
  Returns natural language summary:
  "I found 3 anomalies in your data:
   • Total sales for order #1234 is 
     3.2x above the average (outlier)
   • March 2023 shows a 43% drop in 
     units sold vs rolling average
   • Ford Make holds 67% of all revenue,
     suggesting high concentration risk"

METHOD 3: get_anomaly_badge(
    anomaly: dict
  ) → dict
  
  Returns:
  {
    "icon": "🔴" | "🟡" | "🔵",
    "colour": "red" | "amber" | "blue",
    "label": str
  }

METHOD 4: run_smart_anomaly_check(
    df: pd.DataFrame,
    question: str
  ) → list[dict]
  
  Called when user asks:
  "any anomalies", "what's unusual",
  "anything wrong", "flag outliers",
  "what stands out"
  
  Runs full detection + returns 
  formatted anomaly cards

The Narration Engine converts data results into 
rich natural language narratives.
Inspired by ISANA narration_engine.py but

Implement class NarrationEngine:

METHOD 1: generate_narration(
    result_df: pd.DataFrame,
    question: str,
    intent: dict | None,
    evidence: dict | None,
    mode: str = "standard"
  ) → dict

  mode: "standard" | "executive" | "detailed"
  
  Returns:
  {
    "headline": str,
    "summary": str,
    "key_findings": list[str],
    "narrative_text": str,
    "data_points": list[dict],
    "trend_comment": str | None,
    "recommendation": str | None,
    "word_count": int
  }

  Logic:
  A) DETECT RESULT TYPE:
     - Single value → scalar narration
     - Single dimension → ranked list narration
     - Multi dimension → grouped narration
     - Time series → trend narration
     - Comparison → delta narration

  B) SCALAR NARRATION:
     "Total revenue across all records 
      is £2.4M"

  C) RANKED LIST NARRATION:
     "Across 8 colour variants, 
      Black leads with £420K (18% of total),
      followed by White at £380K (16%).
      Silver is lowest at £89K (4%)."

  D) GROUPED NARRATION:
     "Breaking down revenue by make and 
      car_type across 24 combinations:
      Ford SUV leads at £320K, while 
      Toyota Hatchback shows the lowest 
      at £42K. Ford accounts for 34% of 
      total revenue across all makes."

  E) TREND NARRATION:
     "Revenue shows an upward trend over 
      the period. The most recent month 
      (Dec 2023) reached £189K, up 12% 
      from Nov 2023 (£169K). The 6-month 
      average is £156K."

  F) KEY FINDINGS (always generate 3):
     - Finding 1: top performer
     - Finding 2: lowest/concern
     - Finding 3: pattern or context

    scenario_result: dict
  ) → str
  Adapts WhatIfEngine output to narrative

METHOD 3: generate_anomaly_narration(

  Adapts AnomalyEngine output to narrative

  ) → bool

  - Contains "why", "explain", "describe",
    "tell me about", "what does", "analyse",

  - Is a what-if question
  - Result has anomalies

STEP 2 — Detect message type:

  is_oob = detect_oob(question)
  is_whatif = whatif_engine.detect_whatif_query(q)
  is_anomaly = any token in question from:
    ["anomaly", "anomalies", "unusual", 
     "outlier", "what's wrong", "flag",
     "anything strange", "stands out"]
  is_followup = detect_followup(question)

STEP 3 — Route and process:

  IF is_oob:
    assistant_message = {
      "role": "assistant",
      "content": "That question is outside

      "message_type": "error",
      "data": {
        "error_type": "out_of_scope",
        "suggestions": 
          proactive_engine
            .get_suggested_questions(working_df)
      }
    }

  ELIF is_whatif:
    WITH st.spinner("🔍 Running scenario..."):
      scenario = whatif_engine
        .parse_scenario(question)
      whatif_result = whatif_engine
        .run_scenario(working_df, scenario)
      narrative = narration_engine
        .generate_whatif_narration(whatif_result)
    assistant_message = {
      "role": "assistant",
      "message_type": "whatif",
      "data": {
        "whatif_result": whatif_result,
        "narration": {"narrative_text": narrative,
                      "headline": "What-If Analysis"}
      }
    }

  ELIF is_anomaly:
    WITH st.spinner("⚠️ Scanning for anomalies..."):
      anomalies = anomaly_engine
        .detect_anomalies(working_df)
      summary = anomaly_engine
        .summarise_anomalies(anomalies)
    assistant_message = {
      "role": "assistant", 
      "message_type": "anomaly",
      "data": {
        "anomalies": anomalies,
        "narration": {"narrative_text": summary,
                      "headline": "Anomaly Report"}
      }
    }

  ELSE: (regular query)
    WITH st.spinner("⚡ Thinking..."):
      result = run_query(working_df, question)
      
      Handle 3 or 4 tuple return:
      if len(result) == 4:
        df_result, sql, err, evidence = result
      else:
        df_result, sql, err = result
        evidence = None
      
      IF err:
        assistant_message = error message
      ELSE:
        narration = narration_engine
          .generate_narration(
            df_result, question, 
            intent=None,
            evidence=evidence,
            mode="standard"
          )
        assistant_message = {
          "role": "assistant",
          "message_type": "query",
          "data": {
            "result_df": df_result,
            "sql": sql,
            "evidence": evidence,
            "narration": narration
          }
        }
