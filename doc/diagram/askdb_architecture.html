2. Query flow (Chat Room)

Primary NLQ path from user question to answer — cache, follow-ups, semantic context, LLM SQL, DuckDB, retry, and presentation.

flowchart TD
  Q["User question"] --> GUARD{"Off-topic?"}
  GUARD -->|yes| OOB["Redirect"]
  GUARD -->|no| CACHE{"Cache hit?"}
  CACHE -->|yes| RUN["Run cached SQL"]
  CACHE -->|no| FOLLOW{"Follow-up?"}
  FOLLOW -->|yes| ANCHOR["Edit SQL anchor"]
  FOLLOW -->|no| BUILD["Semantic context"]
  ANCHOR --> GEN["LLM generate SQL"]
  BUILD --> GEN
  GEN --> GUARDSQL{"Guardrails OK?"}
  GUARDSQL --> EXEC["DuckDB execute"]
  EXEC --> ERR{"Error?"}
  ERR -->|yes| HEAL["Retry and self-heal"]
  HEAL --> EXEC
  ERR -->|no| OUT["Results"]
  RUN --> OUT
  OUT --> UI["Table + chart + trust + narration"]
