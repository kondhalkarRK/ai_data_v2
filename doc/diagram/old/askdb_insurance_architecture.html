3. Step table — what leaves the warehouse?

# Component What happens Data to Streamlit
1 Chat User types question; optional incomplete → 2 suggestions. None
2 Semantic + LLM Glossary/domain rules + schema → one PostgreSQL SELECT. None (prompt text only)
3 Guardrails Read-only check; block DML/DDL. None
4 PostgresBackend Wrap LIMIT 1001, ~30s timeout, pooled connection as askdb_app. None yet
5 PostgreSQL Joins/aggregates on ~1.5M claims / premium months. ≤ ~1,000 result rows
6 UI render Format dates, 1-based index; Insight / Table / Chart. Paint ≤ 100 rows in chat

4. Where data lives vs what UI holds

Lives in PostgreSQL

  • fact_claims ~1.5M
  • fact_policy_monthly ~1.4M
  • dims: policy, product, region, agent
  • All heavy GROUP BY / JOIN work

Lives in Streamlit session

  • Chat messages + last SQL anchor
  • Tiny result DataFrames
  • Activated semantic YAML context
  • Never the full warehouse tables

6. Sound bites for the room
