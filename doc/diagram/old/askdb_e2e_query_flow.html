Step-by-step when a user asks a question

# Where What happens What leaves the warehouse
1 Streamlit Chat User types a question; spinner shows a common ASK-DB status. None
2 NLQ engine OOB check, cache, semantic context from YAML + schema. None
3 LLM Writes one PostgreSQL SELECT / WITH. None
4 sql_guardrails Blocks DML/DDL; read-only only. None
5 PostgresBackend Wraps SQL with LIMIT 1001, 30s statement timeout. None yet
6 PostgreSQL Executes aggregates / joins on indexed tables (1.5M+). ≤ 1,000 rows to app
7 Streamlit Shows table/chart (display cap 100), narrative, evidence. Already small
