2. Question flow (DFD)

flowchart TD
  A[1 User question] -->|plain English| B[2 Router]
  B -->|off-topic| C[Polite redirect]
  B -->|follow-up| D[3 Edit prior SQL]
  B -->|new question| E[3 Semantic + OKF]
  D --> F[4 Generate / modify SQL]
  E --> F
  F -->|safe SQL| G[5 DuckDB runs query]
  G -->|rows| H[6 Narration + Trust + Citations]
  H -->|table chart story| I[7 Answer in Chat]
