Platform overview

Ask DB is not a second Power BI. It is the contract for what Revenue, Dealer, and Claims mean — then Chat, Builder, and dashboards all use that contract.

Executive Intelligence

  • KPI cards sit at the top — the first thing leadership sees.
  • Period and Business Health live in the right panel.
  • Progressive explorer is a heatmap: Region → State → City. Use Home, Back, and Reset view so you never get stuck.
  • Ask detailed questions in AI Chat, not on this page.

Analytics Builder

Left panel: Metrics, Dimensions, Advanced Analytics. Top: filters and query summary. Center: large chart/table preview. Run Query compiles governed SQL. Save analyses for reuse.

Semantic Atlas & exploring ontology

Glossary, semantic model, and Knowledge Graph. In the Ontology Browser, use search, map views, and Full Screen for exploration. Hover chips for what Lineage, Hierarchy, and other maps mean.

Knowledge Hub & uploading documents

  1. Click Upload document (or Try Demo / sample files).
  2. Wait until chunks appear.
  3. Search the library or continue in AI Chat with citations.

Data Trust Center

Trust score, quality trends (with axes and values), incidents, and schema drift. Use this before arguing about a KPI movement.

AI Chat & running analytics

Ask in business language. The router chooses SQL, documents, or both. Prefer certified measures from the glossary. Stress-test with docs/ai-testing-questions.md.

Common use cases

  • Board snapshot → heatmap drill → ontology path for Revenue.
  • Analyst compose in Builder without writing joins.
  • Policy question: Knowledge Hub + Chat citation.

Best practices

  • Start from a certified metric, not a raw table.
  • Check Data Trust when a number surprises you.
  • Do not maintain a second definition of Revenue in Power BI if this layer is the contract.

FAQs

Does this replace Power BI? No. It is the source of truth Power BI should consume.

Where did System Logs go? Admin only. Analysts use Query History.

Why Knowledge Hub? Clearer than “Knowledge” — documents that give AI business context.
