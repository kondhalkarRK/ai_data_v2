# Scio brand assets

The supplied brain mark is retained for Light, Dark, and AI themes. The Scio wordmark uses the existing blue and teal treatment.

- `logo-mark.png` / `logo-mark-dark.png`: marks used by the application.
- `logo-wordmark.svg` / `logo-wordmark-dark.svg`: Scio wordmarks.
- `logo-loading.svg`: loading mark.
- Existing source and lockup PNG files are retained as source artwork; the application renders its current wordmark through `BrandWordmark`.

Product text is defined in `apps/web/lib/brand.ts`.
