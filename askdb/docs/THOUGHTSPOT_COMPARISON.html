Architecture rules to preserve

A board stores Answer references, not copied results. Queries, shared views and background jobs must apply current viewer permissions. Typed context cannot override security. Semantic revisions require dependent answers, coaching and caches to be revalidated.

Reuse the current planners, compilers, structured analysis specs, driver narration and regression suites. Defer broad agent orchestration, warehouse writeback, notebooks, numerous connectors and native mobile apps until there is a concrete user need.

Evidence boundaries

This is a public-documentation review, not a logged-in ThoughtSpot trial or a comparative performance benchmark. Features differ by release and experience. Public user/developer guides disagree about new side-panel embedding availability; the new experience also documents feature gaps. Confirm the target release and tenant settings.
