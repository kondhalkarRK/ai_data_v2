Architecture implemented
Layer	Implementation
Flag
ASK_ME_RAG_ENABLED (default false); mutations → 403 rag_disabled
Metadata
PostgreSQL (knowledge_documents, chunks, ACL, ingest jobs)
Blobs
Private local paths under server-generated keys; Azure hook reserved
Vectors
Qdrant with provider/model/dimension-aware collections
Embeddings
sentence_transformers or openai_compatible (no hash when RAG on)
Jobs
Durable PG queue, leases, SKIP LOCKED, retries, idempotency
Worker
In-process POC + python -m app.rag.worker
ACL
Central search_authorized; admin does not bypass chat ACL; region fail-closed
Chat
Grounded LLM for knowledge; hybrid = SQL + citations (no second RAG LLM)
UI
Knowledge Hub gated by capabilities.ragEnabled + Admin mutations
